ATTENTION : le projet Firebase « rayons-frais » n'a qu'UN SEUL fichier de règles,
partagé avec l'appli « Rayons frais ». Ne remplace pas tes règles actuelles :
AJOUTE simplement le bloc ci-dessous à l'intérieur de « match /databases/{database}/documents { … } »,
à côté des règles existantes, puis publie.

Remplace l'adresse e-mail par celle de ton compte de connexion.

    // --- Stocks (justesse des stocks et démarque) ---
    match /magasins/{magasinId}/{document=**} {
      allow read, write: if request.auth != null
        && request.auth.token.email in ['ton.adresse@exemple.fr'];
    }

Pour autoriser plus tard une autre personne, ajoute son e-mail dans la liste :
['ton.adresse@exemple.fr', 'autre.adresse@exemple.fr']
